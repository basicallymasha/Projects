# Projects

CL_Cup Moscow 2025_X5.pdf - создание фиджитал продукта, объединяющего категорию готовой еды с другими сервисами экосистемы X5. Анализировала рынок, потребительские сегменты и возможности кросс-сервисной интеграции.
Демонстрируемые навыки:
1. Работа в команде
2. Аналитическое мышление
3. Figma


CupRussia_2025_P&G_Горизонт_событий_compressed.pdf - внедрение системы маркировки "Честный знак" в производственные процессы P&G. Рассматривала различные способы нанесения Data Matrix кодов и оценивала затраты на модернизацию заводов и складов.
Демонстрируемые навыки:
1. Работа в команде
2. Аналитическое мышление
3. SQL


RNN_для_предсказания_следующего_символа_в_тексте.ipynb - реализация рекуррентной нейронной сети с нуля для предсказания следующего символа в тексте. Модель обучалась на отрывке из "Алисы в Стране чудес" для генерации последовательностей символов. 
Демонстрируемые навыки:
1. Python
2. Machine Learning
3. Аналитическое мышление


Горизонт Событий HSCC GRP.pdf - разработка кредитного продукта для селлеров маркетплейсов, включающего долгосрочный кредит и факторинг. Анализировала потребности целевой аудитории и оценивала экономический эффект от внедрения.
Демонстрируемые навыки:
1. Работа в команде
2. Аналитическое мышление
3. Excel

Линейная_и_квадратичная_регрессия.ipynb - построение моделей регрессии для прогнозирования цены дома на основе его площади. Сравнивались линейная и квадратичная модели с визуализацией результатов и оценкой качества через коэффициент детерминации. 
Демонстрируемые навыки:
1. Математическая статистика
2. Регрессионный анализ
3. Python (Pandas, NumPy, Matplotlib)



Предсказание стоимости квартиры в мегаполисах.ipynb - модель машинного обучения, предсказывающая стоимость квадриры в российском мегаполисе (Москва, Санкт-Петербург и др.). Произвела очистку данных и обучила модель при помощи sklearn.
Демонстрируемые навыки:
1. Machine Learning
2. Python (Sklearn, Pandas, NumPy, Matplotlib)
3. Внимание к деталям
